# Native Scholara
The user authorized replacing the inherited Tauri architecture entirely. Only edit this repository; the sibling `scholara` is reference-only. SwiftUI/AppKit UI, PDFKit, native EPUB layout, SQLite, Keychain, URLSession. No web runtime. Build with `swift build`; test with `swift run ScholaraChecks`; package with `scripts/build-app.sh`. Record optimizations and honest limitations in docs/native. No automatic book indexing: every book requires explicit consent or its Embed menu action. Model IDs are editable configuration, never an allowlist. Never commit user data or API credentials. Commit cohesive iterations.
